## YAML决定

新增glp1r_focused_revalidated.yaml：删除midhelix的8–24螺旋提示，保留28..32、线性肽和Q234/W306/R380三个位点。其有效设置等同于原focused，是回退基线，不是假称改进后的新算法。revalidated指本次重新审查配置，不表示服务器运行或实验验证通过。

目前没有数据支持继续扩大热点、固定N端loop、收窄长度或禁止Pro/K/R来解决方向问题，因此不添加这些约束。序列去重只能改善最终选择多样性，不能反过来保证生成方向；逆折叠阶段的氨基酸限制也不能直接修复已有反向骨架。

优先检查两组实际使用的config/design.yaml、steps.yaml及运行命令，确认配置路径、secondary_structure条件和模型版本。保存完整执行配置和种子信息。然后对既有较好的候选（上一轮focused rank03、rank08）做独立复预测；跨批重复的id必须连同批次和序列识别，不能只按_15或_09识别。此复预测属于评估，不是将既有序列重新作为de novo生成模板。

如果需要再做一个小批量复现，在glp1r_peptide目录执行：

```bash
boltzgen check glp1r_focused_revalidated.yaml
boltzgen run glp1r_focused_revalidated.yaml --output runs/round5_focused_recheck --protocol peptide-anything --num_designs 25 --budget 25 --devices 2
```

请使用全新输出目录。保留全部结构和pass_filters字段，budget不保证所有导出候选都通过筛选。若已有复现结果仍全部反向，应暂停扩大该配置的生成量，先研究当前版本是否有经过验证的端点几何控制或其他设计流程；不要编造不受支持的YAML距离字段，也不要用共价bond伪装非共价方向约束。
